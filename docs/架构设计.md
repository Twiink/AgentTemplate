# 架构设计

## 概览

AgentTemplate 是一个模块化的 Agent 后端开发模板，提供 minimal 和 full 两档预设。核心设计原则：

- **模块化**：可选能力以模块形式提供，按需启用
- **类型安全**：使用 Pydantic 和类型注解，编译期发现错误
- **安全优先**：多租户隔离、RLS、工具治理、审批流程
- **可观测**：结构化日志、指标、追踪、错误追踪
- **生产就绪**：启动预检、健康检查、租约恢复、断线续传

## 数据流

### minimal 档同步执行

```
Client
  ↓ POST /threads/{id}/runs/stream
API Server
  ↓ 校验输入、锁定线程
Database (写入 run)
  ↓
Executor (请求内执行)
  ↓ 调用 LangGraph
Checkpointer (连接池)
  ↓ 保存检查点
  ← 读取检查点
  ↓
Model Gateway
  ↓ 调用 LLM
LLM Provider
  ←
  ↓
Tool Registry
  ↓ 执行工具
Tools (governed)
  ↓ 写操作需审批
  ← 返回结果
  ↓
Event Bus (进程内)
  ↓ 实时推送
SSE Stream
  ↓
Client (接收事件)
```

### full 档后台执行

```
Client
  ↓ POST /threads/{id}/runs
API Server
  ↓ 校验输入、写入 run、outbox
Database (事务)
  ↓ 事务提交后
  ↓ 立即投递一次
Celery (send_task)
  ↓
Redis (broker)
  ↓
Worker (常驻事件循环)
  ↓ 领取任务（租约 + fencing）
  ↓ 持有行锁
Database (lease_token)
  ↓
Executor
  ↓ 调用 LangGraph
  ↓ 文本增量合并
Redis Streams (事件流)
  ↓ 关键事件同时写库
Database (run_events)
  ↓
Client
  ↓ GET /runs/{id}/stream (Last-Event-ID)
  ↓ XREAD BLOCK
Redis Streams
  ↓ 或回放数据库
Database (run_events)
  ↓
Client (接收事件)
```

## 模块机制

每个模块在 `src/app/modules/<名称>/__init__.py` 导出 `module` 对象：

```python
from app.modules import Module, CATALOG

module = Module(
    CATALOG["storage"],          # 元数据
    models="app.modules.storage.models",
    router=router,               # 返回 APIRouter
    setup=setup,                 # async def setup(container)
)
```

### 模块契约

| 字段 | 类型 | 说明 |
|---|---|---|
| `catalog` | `ModuleCatalog` | 模块元数据（name、requires、tables、extras） |
| `models` | `str | None` | 模型模块路径（用于迁移发现） |
| `router` | `Callable[[], APIRouter] | None` | 路由工厂 |
| `setup` | `Callable[[Container], Awaitable[None]] | None` | 启动钩子 |

### 装配顺序

1. 加载配置，解析 `preset` 和 `modules`
2. 校验模块依赖关系
3. 初始化日志
4. 执行启动预检
5. 建立核心资源（数据库、Redis、模型、Checkpointer）
6. 按依赖顺序启动模块（调用 `setup`）
7. 发现并构建 Agent
8. 注册路由
9. 开始服务

### 迁移管理

- 核心迁移：`src/app/db/migrations/`，分支标签 `core`
- 模块迁移：各模块 `migrations/`，分支标签为模块名
- `migrate` 只升级核心分支和已启用模块的分支
- 停用模块不删除其表，但不再执行其迁移

## Agent 注册

### AgentSpec 契约

```python
@dataclass(frozen=True)
class AgentSpec:
    id: str                          # 唯一标识
    description: str                 # 描述
    build: Callable                  # 构建工厂
    input_schema: type[BaseModel] | None = None
    context_schema: type | None = None
    mcp_servers: tuple[str, ...] = () # 启动前连接的 MCP 服务名
```

### BuildContext

```python
@dataclass(frozen=True)
class BuildContext:
    settings: Settings
    models: ModelGateway             # 按别名获取模型
    tools: ToolRegistry              # 按名称获取工具
    prompts: PromptLoader            # 加载 Prompt
    checkpointer: AsyncPostgresSaver # 必须使用
    store: BaseStore | None          # 启用 memory 时可用
```

### 自动发现

启动时扫描 `app.agents.*.agent`，导入并验证 `spec`：
- ID 重复：启动失败
- 构建失败：启动失败
- `agents.enabled` 非空时：只启用列表中的 Agent

    run_id: str
    thread_id: str
    agent_id: str

## 安全边界

### 多租户隔离

- 身份只能来自已验证凭据（API Key 或 JWT）
- 所有业务表继承 `Owned` 混入（tenant_id、subject_id）
- 启用 PostgreSQL RLS
- 线程命名空间由服务端生成：`{tenant_id}/{thread_id}`
- 客户端和模型都不能覆盖身份字段

### 工具治理

- Agent 绑定的工具通过 `ToolRegistry` 统一校验 scope、超时、并发和副作用
- 读工具需要 `tools:<name>:read` scope
- 写工具需要 `tools:<name>:write` scope
- 写操作默认需要人工审批（通过 `interrupt`）
- 副作用账本以 `tool_call_id` 为键，恢复时幂等

### 路径与网络

- 文件工具：逐级打开路径，拒绝符号链接、绝对路径、越界
- HTTP 工具：逐跳检查域名和实际连接 IP，拒绝私网
- SQL 工具：只读事务、无特权角色、表允许列表

## 可观测性

### 日志

- structlog + 自定义处理器
- 字段：request_id、trace_id、span_id、tenant_id、subject_id、run_id、agent_id
- 脱敏：字段名（api_key、password、token）+ 正则
- JSON 格式（生产）或控制台格式（本地）

### 指标

23 个 Prometheus 指标：
- HTTP：请求数、延迟
- LLM：请求数、延迟、TTFT、token、费用、降级
- 工具：调用数、延迟
- 运行：总数、延迟、队列深度、活跃数
- 系统：连接池、限流拒绝

### 追踪

- OpenTelemetry SDK
- GenAI 语义约定
- 自动埋点：FastAPI、httpx、SQLAlchemy、Redis、Celery
- LangChain 埋点：OpenInference
- 可选正文采集（需配置脱敏）

### 错误追踪

- Sentry 集成
- 自动捕获未处理异常
- 附加上下文：tenant、run、agent

## 配置分层

优先级（低到高）：
1. `config/base.yaml` - 基础默认值
2. `config/presets/{preset}.yaml` - 预设
3. `config/{env}.yaml` - 环境配置
4. `config/private.yaml` - 私有配置（.gitignore）
5. `AGENT_*` 环境变量 - 嵌套用 `__`，字典/列表用 JSON
6. 程序显式覆盖

敏感配置使用 `SecretStr`，配置文件不提交凭据。

## 性能考虑

### 连接池

- 业务连接池：`database_pool_size`（默认 10）
- Checkpointer 连接池：`database_pool_size`（独立）
- Fence 连接池：`database_pool_size // 2`（独立）

### 缓存

- 配置：一次加载
- 模型：惰性创建，全局单例
- Agent：启动时构建一次
- 就绪探针：结果缓存 2 秒

### 并发

- 线程互斥：advisory lock
- 运行租约：行锁 + lease_token
- 事件序号：递增（行锁内）
- Worker 常驻：事件循环和资源容器

## 扩展点

- 新增 Agent：`src/app/agents/<名称>/agent.py`
- 新增全局工具：`src/app/tools/` 并注册 `ToolDefinition`；Agent 专用工具通过 `ctx.tools.langchain(..., custom=[...])` 绑定
- 新增模块：`src/app/modules/<名称>/`，导出 `module`
- 新增模型服务商：`llm.models` 中配置 `provider`
- 新增 MCP 服务：`config` 中的 `mcp` 字段
- 新增评分器：`evals/scorers/`
