# 评测框架使用指南

## 概述

AgentTemplate 提供了完整的评测框架，支持：

- 内置评分器（exact_match、contains、similarity）
- 并发执行
- 进度显示
- 基线对比
- 回归检测

## 快速开始

### 1. 创建数据集

在 `evals/datasets/` 创建 JSONL 文件：

```jsonl
{"id": "case-1", "agent_id": "assistant", "input": {"messages": [{"role": "user", "content": "什么是 Python？"}]}, "expected": "Python"}
{"id": "case-2", "agent_id": "assistant", "input": {"messages": [{"role": "user", "content": "1+1等于几？"}]}, "expected": "2"}
{"id": "case-3", "agent_id": "assistant", "input": {"messages": [{"role": "user", "content": "列出三种编程语言"}]}, "expected": ["Python", "JavaScript", "Java"]}
```

**字段说明：**

- `id` - 用例唯一标识
- `agent_id` - 被测 Agent ID
- `input` - 传给 Agent 的输入（通常是 messages）
- `expected` - 期望输出（评分器自行解释）
- `options` - 可选的运行配置

### 2. 使用内置评分器

```bash
# 精确匹配
agent-template evaluate \
  --dataset evals/datasets/my_test.jsonl \
  --scorer evals.scorers.builtin:exact_match \
  --output results.json

# 包含检查
agent-template evaluate \
  --dataset evals/datasets/my_test.jsonl \
  --scorer evals.scorers.builtin:contains \
  --output results.json

# 相似度
agent-template evaluate \
  --dataset evals/datasets/my_test.jsonl \
  --scorer evals.scorers.builtin:similarity \
  --output results.json

# 组合评分（所有指标）
agent-template evaluate \
  --dataset evals/datasets/my_test.jsonl \
  --scorer evals.scorers.builtin:combined \
  --output results.json
```

### 3. 并发执行

```bash
# 4 个并发
agent-template evaluate \
  --dataset evals/datasets/my_test.jsonl \
  --scorer evals.scorers.builtin:combined \
  --output results.json \
  --concurrency 4
```

输出示例：

## 内置评分器

### exact_match

精确匹配评分器，输出与期望完全一致得分 1.0，否则 0.0。

```python
# expected 支持多种类型
{"expected": "Python"}                    # 字符串
{"expected": {"answer": "Python"}}        # 对象（JSON 比较）
{"expected": ["a", "b", "c"]}            # 数组（JSON 比较）
```

### contains

包含评分器，期望内容是输出的子串得分 1.0，否则 0.0。

```python
# 字符串：检查是否为输出的子串（不区分大小写）
{"expected": "Python"}

# 列表：检查所有项是否都在输出中
{"expected": ["Python", "JavaScript", "Java"]}
```

### similarity

相似度评分器，使用 SequenceMatcher 计算字符串相似度（0.0-1.0）。

适用于文本生成任务，允许部分差异。

### combined

组合评分器，返回 exact_match、contains、similarity 三个指标。

## 自定义评分器

在 `evals/scorers/` 创建评分器：

```python
# evals/scorers/custom.py
from typing import Any

def accuracy_scorer(record: dict[str, Any]) -> dict[str, float]:
    """自定义准确率评分器。"""
    expected = record.get("expected")
    output = record.get("output")
    
    # 实现评分逻辑
    correct = expected.lower() in str(output).lower()
    
    return {
        "accuracy": 1.0 if correct else 0.0,
        "confidence": output.get("confidence", 0.0),
    }

async def llm_judge_scorer(record: dict[str, Any]) -> dict[str, float]:
    """使用 LLM 作为评判器（支持异步）。"""
    import httpx
    
    # 调用 LLM API
    response = await httpx.post(
        "http://localhost:8000/api/v1/chat",
        json={
            "messages": [
                {
                    "role": "user",
                    "content": f"评判以下回答的质量（0-1）：\n"
                               f"问题：{record['input']}\n"
                               f"回答：{record['output']}\n"
                               f"期望：{record['expected']}"
                }
            ]
        }
    )
    
    score = float(response.json()["message"]["content"])
    
    return {"llm_judge": score}
```

使用自定义评分器：

```bash
agent-template evaluate \
  --dataset evals/datasets/my_test.jsonl \
  --scorer evals.scorers.custom:accuracy_scorer \
  --output results.json
```

## 基线对比与回归检测

### 1. 创建基线

首次运行保存为基线：

```bash
agent-template evaluate \
  --dataset evals/datasets/my_test.jsonl \
  --scorer evals.scorers.builtin:combined \
  --output baseline.json
```

### 2. 对比新版本

```bash
agent-template evaluate \
  --dataset evals/datasets/my_test.jsonl \
  --scorer evals.scorers.builtin:combined \
  --output current.json \
  --baseline baseline.json \
  --threshold 0.05  # 允许最多下降 5%
```

如果任何指标下降超过阈值，命令返回非零退出码（适合 CI 集成）。

## CI 集成

### GitHub Actions

```yaml
name: Evaluation

on:
  pull_request:
    branches: [main]

jobs:
  evaluate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: "3.12"
      
      - name: Install dependencies
        run: |
          pip install uv
          uv sync
      
      - name: Run evaluation
        env:
          AGENT_EVALUATION_TOKEN: ${{ secrets.EVALUATION_TOKEN }}
        run: |
          uv run agent-template evaluate \
            --dataset evals/datasets/smoke_test.jsonl \
            --scorer evals.scorers.builtin:combined \
            --output results.json \
            --baseline evals/baselines/main.json \
            --threshold 0.05 \
            --concurrency 4
      
      - name: Upload results
        if: always()
        uses: actions/upload-artifact@v3
        with:
          name: evaluation-results
          path: results.json
```

## 观测集成

评测结果自动推送到配置的观测后端（Langfuse/LangSmith）：

```yaml
# config.yaml
tracing:
  langfuse_url: "https://langfuse.example.com"
  langfuse_public_key: "pk_..."
  langfuse_secret_key: "sk_..."
```

每个评估用例的评分会自动关联到对应的 trace。

## 最佳实践

1. **分层数据集**
   - `smoke_test.jsonl` - 快速冒烟测试（10-20 用例）
   - `regression.jsonl` - 回归测试（100+ 用例）
   - `benchmark.jsonl` - 基准测试（完整数据集）

2. **合理的阈值**
   - 开发阶段：`--threshold 0.1`（宽松）
   - CI 检查：`--threshold 0.05`（适中）
   - 发布前：`--threshold 0.02`（严格）

3. **并发控制**
   - 开发机：`--concurrency 2-4`
   - CI 服务器：`--concurrency 4-8`
   - 避免超过 API 限流

4. **数据集管理**
   - 使用 Git LFS 存储大型数据集
   - 定期更新基线
   - 记录数据集版本

5. **评分器设计**
   - 返回多个维度的指标
   - 使用有意义的指标名称
   - 确保评分函数是确定性的

## 故障排除

### 身份验证失败

设置评估令牌：

```bash
export AGENT_EVALUATION_TOKEN="your-token"

# 或使用开发者密钥
echo "your-token" > .data/developer.key
```

### 并发问题

降低并发度或增加超时：

```yaml
# config.yaml
run_timeout_seconds: 300  # 默认 120
lease_seconds: 60         # 默认 30
```

### 评分器错误

检查评分器返回格式：

```python
# 正确
return {"metric1": 0.9, "metric2": 0.8}

# 错误
return 0.9  # 必须是字典
return {"metric": "high"}  # 值必须是数值
return {"metric": float('inf')}  # 值必须是有限数值
```
