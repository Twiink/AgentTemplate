# 如何新增工具

本指南演示如何在 AgentTemplate 中创建新的工具。

## 内置工具 vs Agent 专用工具

- **内置工具**：通用工具，放在 `src/app/tools/builtin/`
- **Agent 专用工具**：特定 Agent 使用，放在该 Agent 目录下

## 创建简单工具

### 1. 定义工具函数

```python
# src/app/tools/builtin/time.py
"""时间工具：获取当前时间、格式化、解析。"""

from datetime import datetime, timezone
from zoneinfo import ZoneInfo
from pydantic import BaseModel, Field

from app.tools.registry import ToolDefinition


class GetCurrentTime(BaseModel):
    """获取当前时间。"""
    timezone: str = Field(
        default="UTC",
        description="时区，如 'UTC'、'Asia/Shanghai'、'America/New_York'"
    )


def current_time(timezone: str) -> dict:
    """获取指定时区的当前时间。"""
    try:
        tz = ZoneInfo(timezone)
    except Exception:
        return {
            "error": "invalid_timezone",
            "message": f"时区 '{timezone}' 不存在",
        }
    
    now = datetime.now(tz)
    
    return {
        "timezone": timezone,
        "iso": now.isoformat(),
        "timestamp": now.timestamp(),
        "year": now.year,
        "month": now.month,
        "day": now.day,
        "hour": now.hour,
        "minute": now.minute,
        "second": now.second,
        "weekday": now.strftime("%A"),
    }
```

### 2. 注册到工具执行路径

通用工具通过 `ToolDefinition` 在 `ToolRegistry.__init__` 中注册，声明名称、参数 schema、执行函数和必需 scope。`current_time` 已预先注册，无需重复添加。注册表先用 schema 校验输入，再以关键字参数调用执行函数；Agent 专用工具可在下面用 `custom` 参数绑定。

### 3. 使用工具

```python
# 在 Agent 中获取
tools = ctx.tools.langchain(["current_time"])
```

## 写工具与审批

模板内置写工具经 `ToolRegistry` 统一执行，包含 scope 校验、默认人工审批、超时和副作用账本。绑定工具不等于授予权限，调用者凭据仍需包含对应 scope。生产环境应保持 `tools.confirm_writes: true`。

```python
def build(ctx: BuildContext):
    return create_agent(
        model=ctx.models.chat("openai-main"),
        tools=ctx.tools.langchain(["file_read", "file_write"]),
        system_prompt="写入文件前先说明目标和变更。",
        checkpointer=ctx.checkpointer,
    )
```

### 人工审批流程

1. Agent 调用写工具
2. 执行中断（`interrupt`）
3. 返回给客户端，等待审批
4. 客户端提交审批决定：

```python
# 批准
POST /api/v1/threads/{thread_id}/runs/wait
{
  "agent_id": "assistant",
  "resume": {"action": "approve"},
  "expected_sequence": 5
}

# 拒绝
POST /api/v1/threads/{thread_id}/runs/wait
{
  "agent_id": "assistant",
  "resume": {"action": "reject", "reason": "不安全的操作"},
  "expected_sequence": 5
}
```

## 访问运行上下文

工具可以通过 `current_run.get()` 访问运行上下文：

```python
from app.runtime.contracts import current_run


async def custom_tool(value: str) -> dict:
    context = current_run.get()
    if not context:
        return {"error": "no_context"}
    
    # 访问身份
    tenant_id = context.principal.tenant_id
    subject_id = context.principal.subject_id
    
    # 访问预算与已累计费用
    remaining_tokens = context.token_budget - context.usage["estimated_tokens"]
    recorded_cost = context.usage["cost"] or 0
    
    # 访问运行信息
    run_id = context.run_id
    thread_id = context.thread_id
    resources = context.resources
    
    return {"result": "..."}
```

## 结构化错误返回

工具应返回结构化结果，而不是抛出异常：

```python
async def call_external_api(query: str) -> dict:
    """调用外部 API。"""
    try:
        # API 调用逻辑...
        return {
            "success": True,
            "data": response_data,
        }
    except TimeoutError:
        return {
            "error": "timeout",
            "message": "API 请求超时",
            "retry_after": 60,
        }
    except ValueError as e:
        return {
            "error": "validation_error",
            "message": str(e),
        }
    except Exception:
        raise
```

## 使用配置

工具可以通过依赖注入获取配置：

```python
# src/app/tools/builtin/custom.py
from app.core.config import ToolConfig


class CustomToolRegistry:
    """自定义工具注册表，持有配置。"""
    
    def __init__(self, config: ToolConfig):
        self.config = config
    
    def create_tool(self):
        """创建工具闭包，捕获配置。"""
        config = self.config
        
        async def custom_tool(value: str) -> dict:
            # 使用 config
            timeout = config.timeout_seconds
            # ...
            return {"result": "..."}
        
        return custom_tool


# 在 ToolRegistry.__init__ 中
from app.tools.builtin.custom import CustomToolRegistry

custom_registry = CustomToolRegistry(self.config)
self.register("custom_tool", custom_registry.create_tool())
```

## Agent 专用工具

对于只有特定 Agent 使用的工具，在 Agent 构建时通过 `custom` 参数绑定。它不会加入其他 Agent 的工具集，但仍由同一个执行器治理：

```python
# src/app/agents/assistant/tools.py
"""助手专用工具。"""

from pydantic import BaseModel, Field
from app.tools.registry import ToolDefinition


class NormalizeTextInput(BaseModel):
    """文本规范化输入。"""
    text: str = Field(description="待去除首尾空白的文本")


def normalize_text(text: str) -> str:
    """去除字符串首尾空白。"""
    return text.strip()


# 在 agent.py 中使用
def build(ctx: BuildContext):
    custom = ToolDefinition(
        name="normalize_text",
        description="去除文本首尾空白",
        schema=NormalizeTextInput,
        function=normalize_text,
        scope="tools:custom:normalize",
    )
    return create_agent(
        model=ctx.models.chat("openai-main"),
        tools=ctx.tools.langchain(["file_read"], custom=[custom]),
        system_prompt="根据请求处理工作区文件和文本。",
        checkpointer=ctx.checkpointer,
    )
```

自定义 scope 必须加入调用者的 API Key。`write=True` 只用于确有副作用的工具，会触发人工审批及账本。不要通过直接构造 `StructuredTool` 绕过执行注册表。

## 工具治理配置

### Scope 要求

工具定义中的 `scope` 字段声明调用该工具所需的权限：

```python
ToolDefinition(..., scope="tools:files:read")
ToolDefinition(..., scope="tools:files:write", write=True)
```

API Key 必须包含对应的 scope：

```yaml
auth:
  api_keys:
    - digest: "..."
      scopes:
        - tools:files:read   # 可以读
        - tools:files:write  # 可以写
```

### 审批策略

默认行为：
- **读工具**：不需要审批
- **写工具**：需要审批

审批由 `ToolDefinition.write` 与 `tools.confirm_writes` 控制；`@governed_tool` 只检查可信运行上下文和权限范围，不提供审批、超时、审计或幂等治理。

### 超时控制

工具超时由 `tools.timeout_seconds` 控制（默认 30 秒）。

### 调用次数限制

模板通过 `recursion_limit` 限制 LangGraph 执行步数，通过 `tools.concurrency` 与 `tools.timeout_seconds` 控制工具并发和单次执行时长。

## 安全考虑

### 路径安全

```python
import os
from pathlib import Path


def safe_open(base_dir: Path, relative_path: str):
    """安全地打开路径，防止越界。"""
    full_path = (base_dir / relative_path).resolve()
    
    # 检查是否在允许目录内
    if not full_path.is_relative_to(base_dir):
        raise ValueError("路径越界")
    
    # 使用 O_NOFOLLOW 拒绝符号链接
    fd = os.open(full_path, os.O_RDONLY | os.O_NOFOLLOW)
    return os.fdopen(fd, 'r')
```

### 网络安全

```python
import ipaddress
from urllib.parse import urlparse


def is_safe_url(url: str, allow_private: bool = False) -> bool:
    """检查 URL 是否安全。"""
    parsed = urlparse(url)
    
    # 只允许 HTTP/HTTPS
    if parsed.scheme not in {"http", "https"}:
        return False
    
    # 不允许内嵌凭据
    if parsed.username or parsed.password:
        return False
    
    # 解析 IP
    try:
        ip = ipaddress.ip_address(parsed.hostname)
        if not allow_private and not ip.is_global:
            return False
    except ValueError:
        pass  # 域名，需要进一步解析
    
    return True
```

### SQL 安全

```python
# 使用参数化查询
async def safe_query(conn, table: str, conditions: dict):
    """安全的查询构造。"""
    # 验证表名在允许列表中
    allowed_tables = ["users", "orders"]
    if table not in allowed_tables:
        raise ValueError(f"表 {table} 不在允许列表")
    
    # 使用参数化
    placeholders = " AND ".join(f"{k} = ${i+1}" for i, k in enumerate(conditions))
    query = f"SELECT * FROM {table} WHERE {placeholders}"
    
    return await conn.fetch(query, *conditions.values())
```

## 常见问题

### 工具未注册

检查 `ToolRegistry.__init__` 中是否调用了 `self.register()`。

### 权限不足

检查 API Key 的 scopes 是否包含工具所需的权限。

### 审批流程卡住

确认客户端正确处理 `interrupt` 事件并提交 `resume`。

### 幂等性问题

LangGraph 自动基于 `tool_call_id` 实现幂等，无需工具显式处理。
