# 配置说明

## 配置分层

AgentTemplate 使用多层配置合并，优先级从低到高：

1. **基础默认值** - `config/base.yaml`
2. **预设配置** - `config/presets/{preset}.yaml`
3. **环境配置** - `config/{environment}.yaml`
4. **私有配置** - `config/private.yaml`（.gitignore）
5. **环境变量** - `AGENT_*` 前缀
6. **程序覆盖** - 代码中显式设置

### 环境变量规则

- **前缀**：所有环境变量使用 `AGENT_` 前缀
- **嵌套字段**：使用双下划线 `__` 分隔，如 `AGENT_LLM__DEFAULT_MODEL`
- **字典和列表**：使用 JSON 格式，如 `AGENT_MODULES='["storage", "background"]'`
- **密钥字段**：优先从环境变量读取，如 `OPENAI_API_KEY`

示例：
```bash
export AGENT_LOG_LEVEL=debug
export AGENT_DATABASE_URL="postgresql+asyncpg://..."
export AGENT_LLM__MODELS__GPT_4__API_KEY="${OPENAI_API_KEY}"
export AGENT_MODULES='["storage", "background"]'
```

## 核心配置字段

### 基础配置

#### preset
- **类型**：`str`
- **可选值**：`minimal`、`full`
- **默认值**：`minimal`
- **说明**：预设档位，决定 `modules` 的默认值

#### modules
- **类型**：`list[str]`
- **可选值**：`storage`、`background`、`knowledge`、`memory`
- **默认值**：由 `preset` 决定
  - minimal: `["storage"]`
  - full: `["storage", "background", "knowledge", "memory"]`
- **说明**：启用的模块列表
- **依赖关系**：
  - `knowledge` 需要 `storage` 和 `background`
  - `memory` 的记忆提取需要 `background`

#### environment
- **类型**：`str`
- **可选值**：`local`、`test`、`staging`、`production`
- **默认值**：`local`
- **说明**：当前环境，影响配置文件加载和默认行为

### 数据库配置

#### database_url
- **类型**：`SecretStr`
- **格式**：`postgresql+asyncpg://user:password@host:port/database`
- **说明**：运行时数据库连接串，使用非特权用户
- **环境变量**：`AGENT_DATABASE_URL` 或 `DATABASE_URL`

#### migration_database_url
- **类型**：`SecretStr | None`
- **默认值**：继承 `database_url`
- **说明**：迁移专用连接串，可使用更高权限

#### database_pool_size
- **类型**：`int`
- **默认值**：`10`
- **说明**：连接池大小
- **注意**：Checkpointer 和 Fence 使用独立池

### Redis 配置

#### redis_url
- **类型**：`SecretStr | None`
- **格式**：`redis://[:password@]host:port/database`
- **默认值**：`None`
- **说明**：Redis 连接串
- **用途**：
  - minimal: 限流、缓存、配额（可选）
  - full: 必需，额外用于 Celery broker 和事件流

### 模型配置

#### llm.models
- **类型**：`dict[str, ModelProfile]`
- **说明**：聊天模型别名白名单，只有声明的别名才能使用
- **字段**：
  - `provider`: 服务商（`openai`、`anthropic`、`google_genai`、`openai_compatible`）
  - `model`: 模型标识（如 `gpt-4o-2024-08-06`）
  - `api_key`: API 密钥（SecretStr，优先从环境变量读取）
  - `base_url`: 自定义端点（可选，用于 openai_compatible）
  - `temperature`: 默认温度（可选）
  - `max_tokens`: 默认最大输出（可选）

示例：
```yaml
llm:
  models:
    gpt-4o:
      provider: openai
      model: gpt-4o-2024-08-06
      api_key: ${OPENAI_API_KEY}
      temperature: 0.7
    claude-3-5-sonnet:
      provider: anthropic
      model: claude-3-5-sonnet-20241022
      api_key: ${ANTHROPIC_API_KEY}
    local-llama:
      provider: openai_compatible
      model: llama3.2
      base_url: http://localhost:11434/v1
      api_key: "not-needed"  # Ollama 不需要
```

#### llm.embeddings
- **类型**：`dict[str, EmbeddingProfile]`
- **说明**：向量模型别名白名单
- **字段**：
  - `provider`: 服务商
  - `model`: 模型标识
  - `api_key`: API 密钥
  - `dimensions`: 向量维度（必需）
  - `base_url`: 自定义端点（可选）

示例：
```yaml
llm:
  embeddings:
    text-embedding-3-small:
      provider: openai
      model: text-embedding-3-small
      dimensions: 1536
      api_key: ${OPENAI_API_KEY}
```

#### llm.default_embedding
- **类型**：`str`
- **说明**：默认向量模型别名，必须存在于 `llm.embeddings`
- **用途**：knowledge 和 memory 模块使用

#### llm.pricing_file
- **类型**：`str`
- **默认值**：`config/pricing.yaml`
- **说明**：价格表文件路径，相对于项目根目录

### Agent 配置

#### agents.enabled
- **类型**：`list[str]`
- **默认值**：`[]`（空列表表示启用全部）
- **说明**：启用的 Agent ID 列表
- **行为**：
  - 空列表：启用所有自动发现的 Agent
  - 非空：只启用列表中的 Agent

#### agents.extraction
- **类型**：`str | None`
- **默认值**：`None`
- **说明**：记忆提取使用的 Agent ID
- **依赖**：需要启用 memory 模块

### 认证配置

#### auth.api_keys
- **类型**：`list[ApiKeyConfig]`
- **说明**：静态 API Key 列表（开发用）
- **字段**：
  - `digest`: SHA-256 摘要
  - `tenant_id`: 租户标识
  - `subject_id`: 主体标识
  - `scopes`: 权限范围列表

示例：
```yaml
auth:
  api_keys:
    - digest: "abc123..."  # echo -n "your-secret-key" | sha256sum
      tenant_id: default
      subject_id: developer
      scopes:
        - resources:read
        - resources:write
        - tools:files:read
        - tools:files:write
        - tools:http
```

**注意**：生产环境使用数据库动态 Key（`apikey` 命令）。

#### auth.jwt_*
- **类型**：多个字段
- **说明**：JWT 认证配置
- **字段**：
  - `jwt_algorithm`: 签名算法（如 `RS256`）
  - `jwt_secret`: 对称密钥（SecretStr）
  - `jwt_public_key`: 非对称公钥（SecretStr）
  - `jwks_url`: JWKS 端点 URL
  - `jwt_issuer`: 签发者（可选）
  - `jwt_audience`: 受众（可选）

示例（JWKS）：
```yaml
auth:
  jwks_url: https://auth.example.com/.well-known/jwks.json
  jwt_issuer: https://auth.example.com
  jwt_audience: agent-api
```

### 工具配置

#### tools.directory
- **类型**：`Path`
- **默认值**：`.data/workspace`
- **说明**：文件工具的工作目录，相对于项目根目录

#### tools.http_allowed_domains
- **类型**：`list[str]`
- **默认值**：`[]`
- **说明**：HTTP 工具允许访问的域名列表
- **格式**：不含协议，如 `["example.com", "api.openai.com"]`

#### tools.allow_private_networks
- **类型**：`bool`
- **默认值**：`false`
- **说明**：是否允许访问私网地址（127.0.0.1、10.x.x.x 等）

#### tools.timeout_seconds
- **类型**：`int`
- **默认值**：`30`
- **说明**：工具执行超时时间

#### tools.max_bytes
- **类型**：`int`
- **默认值**：`10485760`（10 MB）
- **说明**：HTTP 响应最大字节数

#### tools.fetch_max_chars
- **类型**：`int`
- **默认值**：`100000`
- **说明**：HTTP 响应截断字符数

#### tools.sql_readonly_url
- **类型**：`SecretStr | None`
- **说明**：只读数据库连接串（用于 SQL 工具）
- **要求**：必须是无特权、只读角色

#### tools.sql_allowed_tables
- **类型**：`list[str]`
- **默认值**：`[]`
- **说明**：SQL 工具允许访问的表名列表
- **格式**：`["users", "orders"]` 或 `["public.users"]`

#### tools.tavily_api_key
- **类型**：`SecretStr | None`
- **说明**：Tavily 搜索 API 密钥

#### tools.tavily_max_results
- **类型**：`int`
- **默认值**：`5`
- **说明**：搜索返回的最大结果数

### MCP 配置

#### mcp
- **类型**：`dict[str, McpServerConfig]`
- **说明**：MCP 服务器配置，键为服务名
- **字段**：
  - `command`: 启动命令（如 `npx`）
  - `args`: 命令参数列表
  - `env`: 环境变量（可选，可引用现有环境变量）
  - `allowed_tools`: 允许使用的工具列表（可选，空表示全部）
  - `write_tools`: 标记为写操作的工具（可选）

示例：
```yaml
mcp:
  filesystem:
    command: npx
    args:
      - -y
      - "@modelcontextprotocol/server-filesystem"
      - /allowed/path
    allowed_tools:
      - read_file
      - write_file
      - search_files
    write_tools:
      - write_file
  github:
    command: npx
    args:
      - -y
      - "@modelcontextprotocol/server-github"
    env:
      GITHUB_PERSONAL_ACCESS_TOKEN: ${GITHUB_TOKEN}
```

### 运行配置

#### run_timeout_seconds
- **类型**：`int`
- **默认值**：`300`（5 分钟）
- **说明**：单次运行的最大时长

#### run_max_input_tokens
- **类型**：`int`
- **默认值**：`100000`
- **说明**：单次运行的输入 token 上限

#### run_max_output_tokens
- **类型**：`int`
- **默认值**：`10000`
- **说明**：单次运行的输出 token 上限

#### run_max_cost
- **类型**：`float`
- **默认值**：`1.0`（1 美元）
- **说明**：单次运行的费用上限

#### run_cost_budget
- **类型**：`float | None`
- **说明**：租户月度费用配额（美元）
- **行为**：超限时返回 429 错误

#### lease_seconds
- **类型**：`int`
- **默认值**：`300`（5 分钟）
- **说明**：后台运行的租约时长（full 档）

### 限流配置

#### rate_limit_per_minute
- **类型**：`int`
- **默认值**：`60`
- **说明**：每个主体每分钟的请求上限

#### rate_limit_failure_mode
- **类型**：`str`
- **可选值**：`open`、`closed`
- **默认值**：`open`
- **说明**：限流后端（Redis）故障时的行为
  - `open`: 放行请求
  - `closed`: 拒绝请求

### 日志配置

#### log_level
- **类型**：`str`
- **可选值**：`debug`、`info`、`warning`、`error`
- **默认值**：`info`
- **说明**：日志级别，不区分大小写

#### log_format
- **类型**：`str`
- **可选值**：`auto`、`json`、`console`
- **默认值**：`auto`
- **说明**：日志格式
  - `auto`: local 环境用 console，其他用 json
  - `json`: 结构化 JSON
  - `console`: 带颜色的控制台格式

#### slow_query_ms
- **类型**：`int`
- **默认值**：`1000`（1 秒）
- **说明**：慢查询阈值（毫秒）

#### redaction_patterns
- **类型**：`list[str]`
- **默认值**：`[]`
- **说明**：追加的脱敏正则表达式
- **内置规则**：自动脱敏 api_key、password、token、secret 等字段

### 追踪配置

#### tracing.enabled
- **类型**：`bool`
- **默认值**：`false`
- **说明**：是否启用 OpenTelemetry 追踪

#### tracing.endpoint
- **类型**：`str | None`
- **说明**：OTLP 端点 URL

#### tracing.headers
- **类型**：`dict[str, str]`
- **说明**：追踪请求头（如认证令牌）

#### tracing.sample_rate
- **类型**：`float`
- **默认值**：`1.0`
- **说明**：采样率（0.0-1.0）

#### tracing.capture_content
- **类型**：`bool`
- **默认值**：`false`
- **说明**：是否采集请求/响应正文
- **警告**：开启时必须配置脱敏规则

#### langsmith.enabled
- **类型**：`bool`
- **默认值**：`false`
- **说明**：是否启用 LangSmith 原生追踪
- **注意**：不能与 `tracing.enabled` 同时开启

#### langsmith.api_key
- **类型**：`SecretStr | None`
- **说明**：LangSmith API 密钥

#### langsmith.project
- **类型**：`str | None`
- **说明**：LangSmith 项目名称

### Sentry 配置

#### sentry.dsn
- **类型**：`SecretStr | None`
- **说明**：Sentry DSN

#### sentry.environment
- **类型**：`str | None`
- **默认值**：继承 `environment`
- **说明**：Sentry 环境标识

#### sentry.traces_sample_rate
- **类型**：`float`
- **默认值**：`0.01`（1%）
- **说明**：性能追踪采样率

### 启动预检配置

#### preflight.enabled
- **类型**：`bool`
- **默认值**：`true`
- **说明**：是否执行启动预检

#### preflight.require_migrations
- **类型**：`bool`
- **默认值**：`true`
- **说明**：是否要求迁移已执行
- **行为**：`false` 时降级为警告

#### preflight.network_timeout_seconds
- **类型**：`int`
- **默认值**：`5`
- **说明**：网络检查超时时间

### 模块配置

#### storage.backend
- **类型**：`str`
- **可选值**：`local`、`s3`
- **默认值**：`local`

#### storage.directory
- **类型**：`Path`
- **默认值**：`.data/attachments`
- **说明**：本地存储目录

#### storage.s3_*
- **类型**：多个字段
- **说明**：S3 存储配置（backend=s3 时）
- **字段**：`s3_bucket`、`s3_region`、`s3_access_key`、`s3_secret_key`、`s3_endpoint_url`

#### memory_retention_days
- **类型**：`int | None`
- **默认值**：`None`（永不过期）
- **说明**：记忆保留天数（memory 模块）

## 配置示例

### minimal 档开发环境

```yaml
# config/private.yaml
preset: minimal
environment: local

database_url: postgresql+asyncpg://postgres:password@localhost:5433/agent_template
redis_url: redis://localhost:6380/0

llm:
  models:
    gpt-4o:
      provider: openai
      model: gpt-4o-2024-08-06
      api_key: ${OPENAI_API_KEY}

auth:
  api_keys:
    - digest: "your-sha256-digest"
      tenant_id: default
      subject_id: developer
      scopes: [resources:read, resources:write, tools:files:read]

tools:
  directory: .data/workspace
  http_allowed_domains: [example.com]
  allow_private_networks: true

log_level: debug
log_format: console
```

### full 档生产环境

```yaml
# config/production.yaml
preset: full
environment: production

# 数据库和 Redis 从环境变量读取
# AGENT_DATABASE_URL、AGENT_REDIS_URL

  models:
    gpt-4o:
      provider: openai
      model: gpt-4o-2024-08-06
      api_key: ${OPENAI_API_KEY}
    claude-3-5-sonnet:
      provider: anthropic
      model: claude-3-5-sonnet-20241022
      api_key: ${ANTHROPIC_API_KEY}
  embeddings:
    text-embedding-3-small:
      provider: openai
      model: text-embedding-3-small
      dimensions: 1536
      api_key: ${OPENAI_API_KEY}
  default_embedding: text-embedding-3-small

agents:
  extraction: memory-extractor

# 生产环境不使用静态 API Key
auth:
  api_keys: []
  jwks_url: https://auth.example.com/.well-known/jwks.json
  jwt_issuer: https://auth.example.com
  jwt_audience: agent-api

tools:
  directory: /app/workspace
  http_allowed_domains: [api.example.com, api.openai.com]
  allow_private_networks: false
  sql_readonly_url: ${READONLY_DATABASE_URL}
  sql_allowed_tables: [users, orders]
  tavily_api_key: ${TAVILY_API_KEY}

storage:
  backend: s3
  s3_bucket: agent-attachments
  s3_region: us-east-1
  s3_access_key: ${AWS_ACCESS_KEY_ID}
  s3_secret_key: ${AWS_SECRET_ACCESS_KEY}

  enabled: true
  endpoint: https://cloud.langfuse.com
  headers:
    Authorization: Bearer ${LANGFUSE_SECRET_KEY}
  sample_rate: 0.1
  capture_content: false

sentry:
  dsn: ${SENTRY_DSN}
  environment: production
  traces_sample_rate: 0.01

preflight:
  require_migrations: true
```

## 配置验证

验证配置正确性：

```bash
# 验证配置
uv run agent-template config validate

# 查看生效配置（脱敏）
uv run agent-template config show

# 指定配置根目录
uv run agent-template config validate --root /path/to/config
```

## 安全最佳实践

1. **不要提交密钥**
   - 使用 `config/private.yaml`（已在 .gitignore）
   - 生产环境从环境变量读取
   - 使用 Secret 管理服务

2. **最小权限原则**
   - 数据库用户无超级用户权限
   - 数据库用户无 BYPASSRLS 权限
   - SQL 工具使用专门的只读角色

3. **生产环境检查**
   - 不使用开发 API Key
   - CORS 不设为 `*`
   - 关闭 `/docs` 端点
   - 开启正文采集时必须配置脱敏

4. **密钥轮换**
   - 定期轮换 API Key
   - 使用数据库动态 Key（支持过期和吊销）
   - JWT 使用短期 token

## 常见问题

### 配置未生效

1. 检查环境变量是否正确设置
2. 检查配置文件加载顺序
3. 使用 `config show` 查看最终配置
4. 检查是否有语法错误（YAML 缩进）

### 模型调用失败

1. 检查 `llm.models` 中是否声明了别名
2. 检查 API Key 是否正确
3. 检查 `base_url`（openai_compatible）
4. 查看日志中的详细错误

### Redis 连接失败

1. minimal 档：Redis 可选，检查 `redis_url` 是否配置
2. full 档：Redis 必需，检查服务是否启动
3. 检查连接串格式和端口
4. 检查网络连接和防火墙

### 迁移失败

1. 检查 `database_url` 是否正确
2. 检查数据库用户权限
3. 使用 `migration_database_url` 提供更高权限
4. 查看迁移日志定位问题
