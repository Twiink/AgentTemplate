# 长期记忆使用指南

## 概述

长期记忆模块现已支持：

- **LangGraph AsyncPostgresStore** 集成
- **语义检索**（向量相似度）
- **关键词检索**（全文匹配）
- **命名空间管理**
- **自动过期清理**

## 快速开始

### 1. 启用语义检索

在应用启动时配置：

```python
from app.core.container import Container

async with Container(settings) as resources:
    # 启用语义检索
    if resources.memories:
        resources.memories.enable_semantic_search("openai-embedding-3-small")
        await resources.memories.initialize()
```

### 2. 存储记忆

```python
import httpx

# 存储记忆
response = httpx.put(
    "http://localhost:8000/api/v1/memories",
    headers={"Authorization": f"Bearer {token}"},
    json={
        "namespace": "user_preferences",
        "key": "programming_language",
        "content": "用户偏好使用 Python 进行数据分析和机器学习",
        "sources": [
            {"type": "conversation", "run_id": "run_123"}
        ],
        "metadata": {
            "category": "preference",
            "confidence": 0.9
        }
    }
)

memory = response.json()
print(f"记忆 ID: {memory['id']}")
print(f"版本: {memory['version']}")
```

### 3. 关键词检索

```python
# 全文匹配检索
response = httpx.get(
    "http://localhost:8000/api/v1/memories",
    headers={"Authorization": f"Bearer {token}"},
    params={
        "query": "Python",
        "namespace": "user_preferences",
        "limit": 20

memories = response.json()["items"]

    print(f"{memory['key']}: {memory['content']}")
```

### 4. 语义检索

```python
# 向量相似度检索
response = httpx.post(

    headers={"Authorization": f"Bearer {token}"},

        "namespace": "user_preferences",
```

## LangGraph 集成

### 使用 AsyncPostgresStore

```python
from langgraph.checkpoint.postgres import AsyncPostgresSaver
from langgraph.store.postgres import AsyncPostgresStore

async def create_agent_with_memory():
    """创建带长期记忆的 Agent。"""
    
    # Checkpointer（短期状态）
    checkpointer = AsyncPostgresSaver.from_conn_string(
        str(settings.database_url)
    )
    await checkpointer.setup()
    
    # Store（长期记忆）
    store = AsyncPostgresStore.from_conn_string(
        str(settings.database_url)
    )
    await store.setup()
    
    # 创建 Agent
    graph = create_graph()
    agent = graph.compile(
        checkpointer=checkpointer,
        store=store,
    )
    
    return agent
```

### 在 Agent 中访问记忆

```python
from langgraph.store.base import BaseStore

async def agent_with_memory(state, *, store: BaseStore):
    """使用长期记忆的 Agent 节点。"""
    user_id = state["user_id"]
    
    # 读取记忆
    namespace = ("user", user_id, "preferences")
    memories = await store.asearch(namespace)
    
    # 使用记忆
    context = "\n".join([
        f"{item.key}: {item.value['content']}"
        for item in memories
    ])
    
    # 保存新记忆
    await store.aput(
        namespace,
        "last_topic",
        {"content": state["current_topic"], "timestamp": ...}
    )
    
    return state
```

## 记忆提取

自动从对话中提取记忆（需要 background 模块）：

```python
# 配置记忆提取
settings.memory_extraction = {
    "enabled": True,
    "agent_id": "memory_extractor",  # 提取 Agent
    "template": "extract_memory",     # Prompt 模板
}

# 提取逻辑在后台自动执行
# 每次运行完成后，会异步调用提取 Agent
```

提取 Agent 示例：

```python
# src/app/agents/memory_extractor.py
from langchain_core.messages import SystemMessage, HumanMessage

async def memory_extractor(state):
    """从对话中提取结构化记忆。"""
    conversation = state["conversation"]
    
    prompt = """
    从以下对话中提取用户的偏好、事实和上下文信息。
    
    对话历史：
    {conversation}
    
    提取格式（JSON）：
    {
      "memories": [
        {
          "namespace": "user_preferences",
          "key": "...",
          "content": "...",
          "metadata": {}
        }
      ]
    }
    """
    
    # 调用 LLM 提取
    response = await llm.ainvoke([
        SystemMessage(content=prompt.format(conversation=conversation))
    ])
    
    # 解析并保存记忆
    memories = json.loads(response.content)
    for memory in memories["memories"]:
        await memory_service.put(
            state["principal"],
            namespace=memory["namespace"],
            key=memory["key"],
            content=memory["content"],
            sources=[{"type": "extraction", "run_id": state["run_id"]}],
            metadata=memory.get("metadata", {}),
        )
    
    return state
```

## 高级用法

### 记忆版本

相同 namespace + key 的记忆会自动递增版本：

```python
# 第一次存储
await memory_service.put(
    principal, "preferences", "language", "Python"
)  # version: 1

# 更新
await memory_service.put(
    principal, "preferences", "language", "Python 和 JavaScript"
```


### 元数据查询

虽然当前 API 不支持元数据过滤，但可以在应用层实现：

```python
# 获取所有记忆
memories = await memory_service.search(principal, "", namespace, limit=1000)

# 应用层过滤
high_confidence = [
    m for m in memories
    if m["metadata"].get("confidence", 0) > 0.8
]
```

## 性能优化

### 向量索引

语义检索需要向量索引：

```sql
-- 检查索引
SELECT indexname, indexdef
FROM pg_indexes
WHERE tablename = 'memories'
  AND indexname LIKE '%embedding%';

-- 创建 HNSW 索引（如果不存在）
CREATE INDEX IF NOT EXISTS memories_embedding_idx
ON memories USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);
```

### 批量操作

对于大量记忆，使用批量接口：

```python
# 批量存储（应用层实现）
async def bulk_put(memories: list):
    tasks = [
        memory_service.put(principal, **memory)
        for memory in memories
    ]
    await asyncio.gather(*tasks)
```

## 与知识库对比

| 特性 | 记忆（Memory） | 知识库（Knowledge） |
|---|---|---|
| **用途** | 短期上下文、用户偏好 | 文档检索、RAG |
| **存储单位** | 键值对 | 文档切片 |
| **更新** | 频繁更新 | 批量导入 |
| **检索** | 按键、全文、语义 | 向量、混合检索 |
| **过期** | 支持自动过期 | 永久存储 |
| **容量** | 适中（KB 级） | 大（GB 级） |

## 最佳实践

1. **合理划分命名空间**
   - 按用途或领域组织
   - 使用层级结构：`category:subcategory:id`

2. **精简记忆内容**
   - 只存储关键信息
   - 避免存储重复内容

3. **设置合理的过期时间**
   - 临时信息：7-30 天
   - 偏好设置：90-180 天
   - 核心事实：不过期（设为 null）

4. **记录来源**
   - 便于追溯和验证
   - 支持记忆合并和冲突解决

5. **使用语义检索**
   - 概念查询优先用语义检索
   - 精确查找用关键词检索

## 故障排除

### 语义检索未启用

错误：`语义检索需要配置 embedding 模型`

解决：

```python
memory_service.enable_semantic_search("openai-embedding-3-small")
await memory_service.initialize()
```

### LangGraph Store 初始化失败

错误：`relation "store" does not exist`

解决：调用 `await store.setup()`

### 向量维度不匹配

确保使用相同的 embedding 模型：

```python
# 配置中指定
memory_service.enable_semantic_search("openai-embedding-3-small")

# 所有记忆使用相同的模型
```

## 示例：个性化 Agent

```python
from langgraph.graph import StateGraph
from langgraph.store.base import BaseStore

async def personalized_agent(state, *, store: BaseStore):
    """使用长期记忆的个性化 Agent。"""
    user_id = state["user_id"]
    query = state["query"]
    
    # 语义检索相关记忆
    namespace = ("user", user_id)
    memories = await store.asearch(
        namespace,
        query=query,
        limit=5
    )
    
    # 构建个性化上下文
    context = "用户信息：\n"
    for item in memories:
        context += f"- {item.key}: {item.value['content']}\n"
    
    # 使用上下文生成回复
    messages = [
        SystemMessage(content=f"你是一个个性化助手。\n\n{context}"),
        HumanMessage(content=query)
    ]
    
    response = await llm.ainvoke(messages)
    
    # 更新记忆
    await store.aput(
        namespace,
        f"interaction_{state['timestamp']}",
        {
            "content": f"Q: {query}\nA: {response.content}",
            "timestamp": state["timestamp"]
        }
    )
    
    state["response"] = response.content
    return state

# 创建 Agent
graph = StateGraph(State)
graph.add_node("agent", personalized_agent)
agent = graph.compile(
    checkpointer=checkpointer,
    store=store,
)
```
